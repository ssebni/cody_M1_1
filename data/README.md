# 분석용 데이터 준비

게시물 원문과 ID가 포함된 CSV는 공개하지 않습니다. 본인 Threads 계정에서 Threads API로 수집한 로컬 파일을 이 폴더에 threads_insights.csv라는 이름으로 배치하거나 analysis.py --input으로 경로를 지정하세요. 입력 스키마·기간·수집 방법은 루트 README.md를 참고하세요. 접근 토큰은 저장소에 포함하지 마세요.

날짜별 총 팔로워 수를 확인한 화면 이력 JSON도 로컬에 follower_history.json으로 준비하거나 --followers로 경로를 지정하세요. 정확한 입력 구조와 서로 다른 관측 기간은 루트 README.md에 설명되어 있습니다. 원본 JSON도 공개에서 제외합니다.
